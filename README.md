**VeriFlow – Web Quality Automation** is a web-based QA automation playground developed using **React, TypeScript, and Playwright**.

The project provides an interactive environment for exploring software testing techniques, implementing automated test cases, and validating web application functionality.

It focuses on practical quality assurance concepts such as sorting, filtering, visual comparison, and functional UI testing.

## ⚙️ Installation & Setup

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git
- Visual Studio Code (optional)

### Step 1: Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/VeriFlow-Web-Quality-Automation.git
```

### Step 2: Navigate to Project

```bash
cd VeriFlow-Web-Quality-Automation
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Install Playwright Browsers

```bash
npx playwright install --with-deps
```

### Step 5: Start Application

```bash
npm run dev
```

### Step 6: Execute Tests

Open a new terminal and run:

```bash
npm run test
```

Refer to `package.json` for the exact available scripts.
